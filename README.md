# Maze Escape - Unity Game

## About
A maze navigation game built with Unity primitives (cubes, spheres, planes).

## Controls
- WASD or Arrow Keys - Move player
- Reach the end of the maze to win

## How to Play
1. Clone the repository
2. Open in Unity (version 2021.3 or newer)
3. Open `Assets/Scenes/MainMenu.unity` (or your main scene)
4. Press Play

## Project Structure
- `Assets/Scripts/` - All C# game logic
- `Assets/Scenes/` - Game scenes
- `Assets/Materials/` - Colors and materials for maze objects
- `Assets/Prefabs/` - Reusable game objects

## Built With
- Unity Engine
- C# scripts
